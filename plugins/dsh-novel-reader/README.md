# 小说阅读原型

适用于 DSH Desktop `>=0.2.2-rc.1`。在会话右侧栏的「开始」页打开「小说阅读」，也可以点已有会话标题栏上的书本图标。

1. 点「起点官网」或「番茄官网」。在 DSH 自带的浏览器里使用网站提供的登录方式和章节导航。
2. 打开一章后回到阅读面板，点「引用当前章」。如果有多个章节标签，请先让目标章节可见，或把该章的地址填进链接框。书名、章节和摘录可以手动修改。
3. 点「填入提问草稿」把内容放进当前会话输入框，检查后自行发送。也可以点「保存笔记」或「记为续读」。
4. 点击笔记的「打开出处」返回官网章节。「导出 Markdown」把当前笔记整理为一个文件。

续读位置在点击「记为续读」时保存到章节级别。笔记和续读保存在 DSH 数据目录的 `novel-reader/library.json`。在 Windows 默认位于 `%USERPROFILE%\.dsh\novel-reader\library.json`。DSH 重启后保留本地笔记和续读，官网登录需要重新完成。官网选段不可用时，可以手动粘贴可复制的摘录，或只写自己的问题和笔记。

本仓库安装副本可通过 Desktop 插件管理器选择这个目录。安装后重新打开 Desktop，再查看右侧栏。插件卸载后仍可保留或备份本地阅读记录。
