# 实现与交付记录

2026-10-30，版本 0.1.7。初版由 DSH 实现，后续按用户指令由 Codex 修复和安装，用户人工验收界面。

0.1.7 适配 DSH Desktop 0.2.1-rc.5。旧包 engines.dsh 精确限制为 rc.3，新宿主官方 evaluatePluginCompatibility 校验会拒绝加载。核对实际 app.asar 中侧栏 slot、工作区 DOM、导航/置顶、展开状态、持久化、实时状态等契约后，将已验证范围更新为 rc.3 或 rc.5；没有配置版本豁免。当前功能实现无需改写，置顶偏好和会话数据不迁移、不重置。核对结果保存为 docs/compatibility-rc5.json，21 项现有回归测试、构建与 dist 加载检查均通过。实际安装回执见 acceptance.md。

0.1.6 增加工作区文件夹和最近会话多项置顶。会话调用原生 uiWorkspace.pinSession/unpinSession 并订阅 pinnedSessionIds；文件夹通过宿主 createSnapshotStore 的 dsh-sidebar-recents.workspace-pins.v1 保存。最新置顶在前，取消恢复普通顺序，五项分页按排序后的列表计算。图钉在悬浮/焦点时显示，已置顶常驻；导航和图钉为两个独立按钮，避免嵌套 button。操作期间防重复提交，失败给出重试提示。

文件夹排序通过局部 flex order 实现，不搬动 React 管理的节点，也不改写原生注册顺序；树形层级内按同级排序。禁用后恢复排序样式和标记，保留持久偏好。DOM/Tab 的原生节点顺序不被改写；视觉置顶由 CSS 排序实现。新控件延用宿主颜色，无持续选中高亮。

0.1.5 复用 uiSession.sessionStatus 和宿主 StateDot 组件，在最近行及所属/祖先工作区显示运行状态。实时状态优先于目录快照，明确 false 会清除动画；子任务按原生 subagentCatalog 汇总到父会话；等待审批/计划确认/回答显示原生 warning 状态。工作区按注册路径逐级汇总并去重，未分组使用空键。原生文件夹无状态 slot，因此只在活动行插入可卸载的 portal 容器，不改动原生文件夹图标或菜单。

性能上缓存工作区关系；状态更新不重新排序最近列表；相同状态不重新扫描 DOM，也不替换动画节点。无轮询、逐会话 retain 或完整历史读取。只订阅一个已有的状态源，卸载清理订阅及全部状态容器。

0.1.4 按用户反馈移除最近条目的持续选中背景和左侧蓝色竖线；保留悬浮及键盘焦点反馈、当前会话的无障碍语义。项目名仅对重复标题显示用于区分，全部条目的 title 悬浮提示包含所属项目；本次仅解释此规则，不改变数据或展示条件。

用户截图暴露 0.1.2 的五项限制仍未生效：旧测试只模拟了直接子行，实际 Desktop 的 ProjectRowItem 使用 HoverCard 包裹。0.1.3 改为逐个顶层组识别后代文件夹行，嵌套组不重复计数，未分组仍占一项。保留原生文件夹顺序和搜索结果。

工作区及最近均支持点击标题独立折叠，并使用统一箭头和键盘按钮语义。折叠不重置各自分页或文件夹状态；开始原生搜索时显示工作区内容。分页按钮统一使用宿主 label-primary，适配浅色黑字及深色主题。完整移除适配时恢复原生标题属性、监听器、隐藏标记及布局。

性能：只监听原生 workspace slot 的结构变化，最近区渲染和原生行内部状态变化不触发列表扫描；同一帧只应用一次。不增加轮询或完整会话历史读取。最近仍复用宿主目录及 openSession。

验证：21/21 测试通过、0 skipped。新增多置顶顺序、五项分页、取消恢复、失效 ID、原生方法绑定及失败传播；React portal 交互覆盖图钉不触发导航/文件夹点击、置顶失败重试、插件实例重建后恢复及订阅/样式清理，DOM 回归覆盖树形同级置顶。原运行状态、收起及跳转测试继续通过。宿主持久存储和 StateDot 在测试中使用接口桩，真实重启和外观由用户验收。构建和 dist loader/apply 检查另行使用有界脚本。各验证限时 120/120/60 秒，Windows Job Object finally 清理。

安装继续使用本地 bundle 副本、依赖链接和原子 profile manifest 更新，不修改官方包或重启现有 Desktop。补充标准中英 locale 显示名称。已独立调用本机 dshmarket 的 readInstalled/readInstalledVersion，确认其已安装数据源能识别本插件；这不等同于已经观察到插件页显示。真实加载状态和发布文件摘要见 acceptance.md。
