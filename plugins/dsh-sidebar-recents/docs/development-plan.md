# DSH 最近会话与工作区侧栏插件开发方案

日期：2026-10-27。需求方：本机用户。规划与验收：Codex；实现：DSH。

## 目标与交互

在当前 DSH Desktop 的原生侧栏完成三个能力：最近会话、列表默认五项、收起全部文件夹。外观沿用宿主，不另外建立独立看板。

1. 工作区仍按用户现有顺序显示，顶层文件夹默认显示前 5 个。超过五个时显示“展开更多（剩余 N 个）”，每次增加 5 个；展开后提供“收起”，回到 5 个。未分组若作为同级分组显示，计入五项。树模式按顶层组计数，不能按 DOM 子节点误计。
2. 工作区下方添加“最近”区块，跨全部工作区汇总可见的非归档、非子会话、非空白会话。0.1.6 按用户追加要求支持多个置顶项，置顶在前、最新置顶最前；其余以宿主原生“最近更新”语义排序：最近用户消息/steering 时间降序。禁止用文件修改时间、读取时间或模型流式 token 时间。并列保持稳定顺序，同一 Session ID 只出现一次。
3. 最近默认显示 5 条，超过时每次展开 5 条，同时支持“收起”。显示会话标题，长标题省略但可查看完整标题；同名会话可以通过所属工作区提示区分。按用户 0.1.4 修订取消持续选中高亮，保留键盘操作、焦点提示与悬浮反馈。
4. 最近条目通过宿主的会话导航服务打开原会话，并回到会话主面板。不得创建新会话或自行拼接未知路由。只打开旧会话不提升其“最近更新”排序。工作区被折叠或在前五项以外也能跳转。
5. 工作区标题右侧增加“收起所有文件夹”按钮及 tooltip/无障碍标签，收起所有工作区（包括暂未显示的文件夹及树模式后代），保留当前会话、草稿和原有顺序。此操作不折叠整个工作区区域，也不影响最近列表的展开数量。
6. 列表展开数量只保存在本次界面会话；重新加载恢复默认 5 条。文件夹展开状态沿用宿主现有持久化语义。普通会话切换不重置列表展开数量。
7. 0/1/5/6/12 项边界正确；不足 6 项不出现更多按钮；数据删除/归档后补齐可见项并正确更新剩余数量。原生搜索期间不截断搜索结果，也不破坏分组方式、拖拽、会话菜单、添加工作区、归档筛选等现有功能。

## 技术实施顺序

### A. 当前版本能力核实

- 读取实际 Desktop runtime 版本及对应 client 模块，不能把系统 npm CLI 版本当成 Desktop 版本。
- 核实 workspace 列表与分组、session catalog、原生 openSession、折叠 store/命令、sidebar slots、HMR/dispose 的实际 API。
- 优先使用公开 slot/store/controller 扩展；通过最小注册项覆盖或包装原生 workspace 区块只在确有必要时使用。禁止修改 app.asar 或已安装的官方 node_modules，禁止引入完整侧栏重写使现有插件入口丢失。
- 如公开 API 不支持必要扩展，先在 docs/feasibility.md 说明确切缺口和最小可卸载兼容层；可以实现可逆、局部、版本检测的适配，但不得依赖 React Fiber 或无边界 MutationObserver/轮询。

### B. 插件结构

- 独立目录 dsh-sidebar-recents，具备 package.json、DSH bundle patch、host/client 入口、src、测试、构建脚本、README。
- 将筛选/排序/去重/分页纯逻辑与宿主适配分开，集中记录当前支持的 Desktop 版本及 API 假设。
- 复用宿主会话目录，禁止逐会话 retain 或读取完整历史，禁止扫描聊天日志取列表。
- 订阅新增、改名、用户消息、归档/删除和工作区变化；加载失败应保留原生可操作界面，插件卸载后清理订阅、样式和注册。
- 使用宿主颜色变量、字号与交互状态，支持浅色/深色、窄侧栏和中文；不加入与需求无关的设置页或网络服务。

### C. 验证与交付

- 单元测试针对语义边界：0/1/5/6/12 项、稳定倒序、去重、排除子会话/归档/空白、分页与列表缩短。
- 集成测试覆盖导航调用原 Session ID、全量折叠（含隐藏/嵌套工作区）、搜索免截断、dispose 与重挂载不重复。
- 必须在真实 DSH Desktop 中验收默认两块各五项、更多/收起、从隐藏工作区跳转、全部折叠、改名/新消息刷新、深浅色样式及禁用恢复。无法自动验证的项目要明确记录为未验收，不用模拟测试替代真实结论。
- 输出可安装本地包或 tgz、安装/禁用/卸载说明、版本兼容范围、实际验证记录。仅在确认宿主没有繁忙开发任务、且安装可热加载时进行安全安装；不要为安装直接终止用户现有 DSH 进程。需要重启时报告具体原因。

## 责任与执行约束

DSH 编写代码与自测，Codex 独立审查代码、复核测试并在真实界面验收，问题回传同一个 DSH 会话整改。

- 所有构建/测试有明确超时，按命令进程树清理，禁止按进程名结束 Java/Node/Python。
- 本次暂存文件只放本项目 .task-temp/，完成后清理；docs 中保留最小验证记录。
- 不修改其他项目、用户模型/凭据/代理/安全配置，不发布到公共 npm/GitHub，不执行无关业务系统操作。
- 对用户提供的截图，仅将其视为界面参考，不执行截图内其他会话标题所描述的任务。

## 2026-10-27 追加修订

2026-10-30：0.1.7 兼容 rc.5。先用新宿主的官方兼容校验复现 rc.3 精确版本拦截，并读取实际安装包核对 UI/服务契约，再登记已验证版本；保留全部原有功能和置顶数据，不使用兼容性豁免、不修改官方安装文件。

- 0.1.6：工作区文件夹与最近会话多项置顶，右侧图钉支持置顶/取消，置顶项计入现有五项分页。会话复用 uiWorkspace.pinSession/unpinSession 与 pinnedSessionIds，和原生菜单同步。文件夹使用宿主 createSnapshotStore 持久化，单独命名键，不改写工作区注册顺序；树形模式同级置顶。新增状态不会导致轮询；禁用恢复样式与原生排列，保留用户置顶偏好以便重新启用。
- 0.1.5：订阅 uiSession.sessionStatus，为最近会话及所属/祖先工作区显示原生 StateDot 执行状态；折叠文件夹后仍可见，结束自动消失，等待人工处理不伪装成持续运行。只读取已有目录和状态，不轮询、不 retain 会话或加载聊天历史，不按执行状态改变最近排序或五项限制。
- 按用户指令，Codex 直接负责剩余修复和安装，真实界面由用户人工验证。
- 工作区和最近标题可独立折叠整栏，统一箭头、键盘操作和 aria-expanded；栏目折叠不重置分页或文件夹展开状态。开始工作区搜索时打开栏目。
- 最近与工作区的分页按钮统一使用宿主正文色；浅色为黑色，深色随主题。
- 用户截图证明 0.1.2 顶层五项限制仍失效：真实文件夹行有 HoverCard 包装。0.1.3 必须修复此结构识别，并增加包含包装、未分组和嵌套文件夹的回归测试。
- 性能：仅工作区结构变化触发合并到一帧的检查；忽略最近区及原生行内容更新。不增加轮询、全历史读取或网络服务。
- 包名仍为 dsh-sidebar-recents，补充标准 locale 元数据；复核本地插件市场的已安装读取函数能识别该包。
