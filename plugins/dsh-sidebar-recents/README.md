# DSH 最近会话与工作区折叠

版本 0.1.8；兼容 DeepSeek Harness Desktop 0.2.1-rc.3、0.2.1-rc.5、0.2.2-rc.1。

0.1.8 修复升级到 0.2.2-rc.1 后因旧版兼容声明被跳过的问题。保留原来的最近会话、置顶与工作区折叠行为；验证范围见仓库 `docs/compatibility-2026-11-05.md`。

- 工作区顶层文件夹默认显示 5 个，每次展开 5 个，可收回前 5 个。
- 工作区下面显示跨工作区的最近会话，默认 5 条，每次展开 5 条；点击打开原会话。
- 工作区文件夹和最近会话都支持置顶多个。悬浮/键盘聚焦时显示右侧图钉，置顶后常驻，再点取消；新置顶项排最前。置顶计入原有五项分页，超过五项手动展开。
- 会话置顶与 DSH 原生菜单共用持久状态；文件夹置顶复用宿主本地持久化存储，重新加载恢复。文件夹取消置顶回到原生排序，树形模式只在同级排序，不拆散父子关系。
- 执行中的会话及所属工作区、上级工作区显示原生状态动画，收起文件夹仍能看到内部任务在运行；悬浮可查看数量。结束后自动消失，等待审批/回答时显示原生等待标记。排序和默认展示数量保持原有规则。
- 仅同名会话额外显示项目名用于区分；所有条目的悬浮提示均包含项目名。最近列表不显示持续选中背景或蓝色竖线，保留鼠标悬浮及键盘焦点反馈。
- 最近的置顶项按置顶顺序在前，其余按宿主最近用户消息时间排序，排除归档、子代理和空白会话；打开旧会话不改变排序。
- 工作区标题旁的“收起所有文件夹”包含当前隐藏和嵌套文件夹，保留当前聊天。
- 点击“工作区”或“最近”标题可分别收起整个栏目，再次打开保留本次展开数量；搜索会显示工作区内容。
- 两处“展开更多 / 收起”统一使用宿主正文颜色（浅色黑字、深色随主题），标题使用一致的折叠箭头。
- 工作区和最近共用滚动区域；搜索保留原生结果，其他侧栏入口保持原样。

## 本机安装与禁用

先运行有界检查：

```powershell
pwsh -NoProfile -File scripts/verify.ps1
```

本地安装（不会退出或重启现有 Desktop）：

```powershell
pwsh -NoProfile -File scripts/install-local.ps1
```

脚本把发布文件复制到 `%USERPROFILE%/.dsh/local-plugins/dsh-sidebar-recents`，建立 Desktop profile 的依赖目录链接，并只在 `package.json` 中登记该依赖与 bundle。写入前备份 manifest，检测并发变化并原子写入。现有 `cordis.patch.yml`、模型、凭据、代理和其他插件设置不改动。已装载插件可由宿主 HMR 更新；启动时被版本检查跳过的插件可能需要重新启动 DSH。以安装目录的当前版本运行时回执确认激活。

禁用可在 DSH 插件页操作，或执行：

```powershell
pwsh -NoProfile -File scripts/install-local.ps1 -Disable
```

禁用只移除本 bundle 的选择，保留安装文件；再次运行安装脚本可启用。卸载可用 DSH 官方插件管理器移除该包。不要用旧备份覆盖整个当前 profile，以免撤销后来其他插件的变化。

`runtime-status.json` 是插件在真实宿主中写出的启动/停止回执，仅含版本、PID 和时间，不含会话内容。它证明宿主已加载，但不替代用户的界面验收。

这是本地 bundle 插件，包名 `dsh-sidebar-recents`，中文显示名“最近会话与工作区折叠”，未发布到公共市场。可在已安装插件中按包名查找；已打开的页面需要刷新数据或重新进入。安装状态以当前 profile 登记、可解析的包及运行时回执一起核对，不能仅凭页面暂未显示判定未加载。

## 开发与兼容

`npm install` 后使用上述有界检查脚本。测试包含真实 React 渲染的 portal 交互，以及带 HoverCard 包装/嵌套文件夹的 DOM 回归，覆盖排序、筛选、分页、栏目折叠、搜索、导航、全量折叠及卸载恢复。缺少关键测试依赖会失败。React 测试依赖仅用于开发，发布插件继续复用宿主 React。

最近数据和导航复用 DSH 服务；工作区分页与布局采用局部 DOM 适配，不修改 app.asar 或官方包，不读取完整聊天历史。适配只观察原生工作区 slot，卸载时恢复标记、样式、订阅和按钮。Desktop 更新后应重新核对 DOM 和服务兼容性。

当前由用户人工验证界面效果。自动检查和实际安装状态见 `docs/acceptance.md`。
