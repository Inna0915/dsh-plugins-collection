# 饭否面板（@local/dsh-meal-panel）

把「饭点 · 员工订餐」（http://172.18.10.59:8081/app/user/calendar）的核心操作搬进 DSH 侧边栏，
固定在**账号（设置）入口正上方**，宽度随侧边栏自适应。

## 界面

带饭勺图标的「饭否午晚」入口始终固定在侧边栏底部，点击它在上方展开或收起浮层；当天已订餐的「午」或「晚」显示为粗体，展开状态记在浏览器 localStorage（`meal.panel.expanded`）。

展开后可逐餐设置，也可点击「批量工作日订餐」，选择日期与餐次、预览并逐项勾选后确认。默认选择午餐并保留已选的「不订餐」，可额外选择晚餐和允许覆盖「不订餐」。支持本月剩余、下个月、未来 7 天及自定义范围（最多 93 天）。

工作日依据 [2026 年官方节假日及调休安排](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)筛选，尚未收录的年份无法预览。已订、截止、锁定、不在公司和无需登记的餐次会跳过。提交按餐次逐条执行，可停止后续；请求异常时核对日历并停止，不自动重试。请保持页面开启。

- 收起时固定展示**当天**（饭点服务所在时区 Asia/Shanghai 的日历日）的午餐/晚餐状态，
  与展开时选中的日期无关；展开后默认回到当天，翻到别的日期再收起也会回到当天。
- 时区与跨天：截止时间按饭点时区（UTC+8）显示，剩余时间用服务端 `serverTime` 校正本机时钟，
  每 30 秒重算一次；当服务端日历跨过午夜，面板会在 30 秒内自动切到新的一天并重新拉取该月数据，
  无需手动刷新。收起态与展开态都适用。
- 点日期胶囊切换要登记的那一天（今天起 7 天），当天已截止/已锁定的餐次只读。
- 点「订 / 不订」立即写回，乐观更新 + 失败回滚提示。
- 「在公司就餐 / 不在公司就餐」是持续生效的个人状态；切到「不在」需二次确认
  （服务端会清除未锁定的选择）。
- `⟳` 手动刷新；`↗` 在新标签打开原网页；每分钟自动刷新一次，窗口获得焦点时也会刷新。
- 未配置用户名时面板内直接输入用户名即可连接（饭点普通用户只校验用户名，无密码）。

## 午餐提醒

北京时间 08:30 时 DSH Host 正在运行，且今天在公司、午餐仍未选择并未截止时，饭否栏会显示「午餐未报」，宿主会通过 DSH-IM 向会话看板通知设置中选定的机器人及目标发送一条提醒。已选「不订餐」、已订餐、不在公司、无餐次或已截止均不触发。栏内标识会随日历刷新及截止时间自动消失。

提醒使用会话看板保存的接收目标，但不受看板完成通知开关控制。08:30 之后才启动 Host 的当天不会补发；次日起正常检查。每账号每天至多尝试发送一次；IM 发送结果不确定时不会自动重发。平台接受请求不代表消息已被阅读。日历或 IM 还不可用时，会在午餐截止前继续尝试检查；当天日历没有午餐（节假日等）时，当天不再请求饭点服务。

## 数据与接口

Host 半在 `ctx.webServer` 上注册 `/meal/api/*`，浏览器端不直连内网地址：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/meal/api/panel?month=YYYY-MM` | 面板快照（今日、状态、整月每日餐次） |
| POST | `/meal/api/selection` | `{date, meal, choice}` → 写回并返回该日 |
| POST | `/meal/api/presence` | `{presence}` → 切换在公司/不在公司 |
| POST | `/meal/api/lock` | `{date, meal, enable}` → 提前锁定/解锁 |
| POST | `/meal/api/login` | `{username}` → 校验并记住用户名 |
| GET | `/meal/api/health` | 配置与登录状态 |

Host 首次请求时用配置中的用户名登录饭点，保存 `SESSION` Cookie 并在失效时自动重登；
运行期用户名写在 `~/.dsh/meal-panel-settings.json`（优先于 patch 配置）。

## 配置

```yaml
- insert:
    - id: meal-panel
      name: '@local/dsh-meal-panel'
      config:
        baseUrl: 'http://172.18.10.59:8081/app'
        username: '王鹏宏'
```

## 验证

`node test/reminder.mjs` 使用模拟日历和 IM 服务验证定时、去重和宿主接线，不发送真实消息。

`node test/batch.mjs` 使用模拟请求验证工作日筛选、跨月及日期范围、餐次条件、账户保护和提交失败不重放，不会写入真实订单。

`node test/live.mjs` 通过插件自己的 HTTP handler 连真实饭点服务，包含实际订餐写入与还原，请确认需要后再运行。
