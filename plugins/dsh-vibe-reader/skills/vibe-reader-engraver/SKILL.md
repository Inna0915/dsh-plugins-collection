# 闲庭导入（刻书匠）

把古诗文整理成闲庭书卷，用工具 `vibe_reader` 写入书库。书卷是用户长期背诵的底本，**原文一个字都不能错**。用户说法很随意（「导入静夜思」「把李白的诗收进来」「入库论语」），按下表判断，**能直接做就直接做，不要反复确认**。

## 先认清用户要什么

| 用户说 | 是什么 | 怎么做 |
|---|---|---|
| 「导入静夜思」「把《陋室铭》加到书库」「收录赤壁赋」 | 篇名 | `search` 篇名；只有一个结果就直接导入 |
| 「导入『会当凌绝顶』那首」 | 名句 | `search` 名句（4 字以上搜全文） |
| 「导入李白的诗」「苏轼的词都收进来」 | 作者 | `search` 加 `author`；结果多时列出前十条请用户挑，用户说「全部」才全导 |
| 「导入《论语》」「把千字文整本放进来」「导入声律启蒙」 | 整本书 | `search` 书名，按书的自然篇章分卷（见「整本书」） |
| 「导入这些：静夜思、春晓、咏鹅」 | 一批篇目 | 逐篇处理 |
| 贴来一段古诗文（「收录这篇」「导入下面的」） | 用户原文 | 用这段原文，不去语料里找 |
| 「给《静夜思》加注」「把师说的注释补上」 | 已有书卷 | `read` 取书卷，补注释、译文后 `import` 并传 `keepOriginal: true` |

## 铁律

1. **不得默写原文。** 原文只能来自工具从语料取得的（`draft`）、用户贴来的，或书库里已有的那一卷（`keepOriginal`）。哪怕你很熟这篇，也不能自己写出原文。语料里找不到、用户也没贴原文时，请用户贴。
2. **正文一字不改。** 分节、注释、译文、名句都不能改动原文的字和标点。看到疑似错字或与课本不同的异文，告诉用户，由用户决定。
3. **只用 `import` 写入**，原文放进 `original`（或用 `keepOriginal`）。不要用文件工具直接写书库目录。
4. 校验失败时按返回的差异位置改书卷正文，**不要改 `original` 去迁就书卷**。

## 默认做法（用户没特别说明时）

- **单篇**：加脉络、注释、译文、名句和配色后导入。
- **一次超过 5 篇**（批量、整本书）：只导原文，`draft` 返回的草稿原样 `import`，不加注；导完告诉用户「想要注释，可以说『给 X 加注』」。这样不会一次花掉大量时间和 token。
- **id** 自己定：小写拼音加连字符（`jingye-si`、`lunyu-xueer`），不用问用户。
- **标签**：课本篇目第一个标签写学段（`小学`、`初中`、`高中`），蒙学读物写 `蒙学`，整本书再加书名。
- **同 id 已存在**：告诉用户书库里已有，问要不要替换；同意才加 `overwrite: true`。给已有书卷加注不算替换，用 `keepOriginal`。

## 从语料找

1. `action: "search"`，`query` 为篇名、词牌、名句或书名，可加 `author`。
   - 默认搜常用集子：古文观止、唐诗三百首、宋词三百首、诗经、千家诗、论语、大学中庸孟子、楚辞、纳兰性德词、蒙学（千字文、三字经新版与传统版、弟子规、增广贤文、朱子家训、百家姓）、蒙学骈文（声律启蒙按韵、幼学琼林按门类各成一篇）。
   - 没找到：加 `deep: true` 再搜全唐诗、全宋词、元曲（首次下载约 36 MB，先告诉用户要等一会儿）。
   - 宋诗还没找到：`collections: ["quansongshi"]` 搜全宋诗（约 25 万首，首次下载 104 MB、约 4 分钟，先征得用户同意）。
   - 先秦两汉典籍可加 `ctext: true` 搜 ctext 书目；取正文需要 API key，没有时就请用户贴原文。
2. 同名、多个版本、同一词牌不同作者时，列出来请用户选。告诉用户出处，例如「唐诗三百首（chinese-poetry 繁体本转简）」。语料版本可能与课本不同（如《静夜思》有「床前看月光」一版），用户要课本版而语料没有时，请他贴原文。
3. `action: "draft"`，`refs` 为选中的 ref（多首合成一卷时传多个并给 `volumeTitle`），`id` 为新书卷 id。返回 `markdown`（草稿）、`original`（清洗后的原文）、`report`（繁简对应、警告）。`report.warnings` 里：
   - 「原文用了异体字」（如千字文「崐冈」、三字经「茍不教」）：原文不能改，告诉用户；要通行字版本就请他贴原文。
   - 「补了标点」（千字文语料无标点）：照用。
4. 需要加注的，在草稿上补全（见下文），正文照抄不动。
5. `action: "import"`，`original` **原样**传 draft 返回的 `original`，`source: "corpus"`。

## 用户贴的原文

1. 简体原文直接用。繁体、或带 `(某 通：某)` 括注的，先 `action: "clean"`（繁体加 `traditional: true`），以返回的 `text` 为原文。
2. 起草书卷，正文从原文逐段照抄。
3. `action: "import"`，`original` 为原文，`source: "paste"`。**只有**用户说过原文已核对（如「这是课本原文」「已核对」），才加 `verified: true`；否则导入后只能阅读，告诉用户在面板点「我已核对」即可背诵。
4. 用户没有原文、只要「某主题的摘编卡片」：`source: "ai"`，不需要 `original`，先说明这类书卷不能背诵。

## 给已有书卷加注

1. `action: "read"`，`id` 为书卷 id（不知道 id 就先 `list`），拿到现有 Markdown。
2. 在上面改节标题、补脉络、注释、译文、名句、配色；正文一个字不动。
3. `action: "import"`，`markdown` 为改好的书卷，`keepOriginal: true`。原文、来源、核对状态都以书库里那一卷为准；正文被改动会被拒绝。

## 整本书

- 按书的自然篇章分卷，卷名「书名·篇名」：《论语》每篇一卷（论语·学而……），《孟子》每篇一卷，诗经按风雅颂下的各组（诗经·周南……），声律启蒙、幼学琼林语料已是一韵、一门类一篇，一篇一卷。千字文、三字经、弟子规这类本来就不长的，整本一卷。
- 单卷不超过约 30 节；动手前告诉用户「将分成 N 卷」，用户没异议就导。
- 每卷都加上书名标签，书架上可按书名筛出全部。

## 结果

- 失败：`stage` 说明哪一步出错（`format` 格式或色名、`original` 原文不一致、`exists` 同 id 已存在、`input` 参数），按 `problems` 改正后重试。
- 成功：告诉用户导入了哪几卷、各几节、有没有加注，以及「闲庭面板会自动刷新出来」。批量时只报总数和失败项，不必逐卷列。

## 书卷格式

```markdown
---
id: loushi-ming
title: 陋室铭
author: 刘禹锡
dynasty: 唐
kind: prose
source: chinese-poetry/蒙学/guwenguanzhi.json
edition: 古文观止（chinese-poetry 繁体本转简）
color: 竹绿
tags: [古文观止, 铭]
---

## 斯是陋室 {#s1}
> 脉络：以山水仙龙起兴，点出陋室因德而馨

山不在高，有仙则名。……

- 【馨】xīn：散布很远的香气，比喻品德高尚

译：山不在于高，有了仙人就出名。……
```

- `id`：小写拼音加连字符，简短、唯一，如 `loushi-ming`。入藏后不要再改。
- `kind`：`poem`（诗词，保留原文换行）、`prose`（文章）、`article`（现代文章）。
- `tags`：统编教材里有的篇目，第一个标签写学段：`小学`、`初中`、`高中`；千字文、三字经一类写 `蒙学`。拿不准学段就不写。其后可加体裁、出处等标签。书架按这些标签筛选。
- `fingerprint`、`verified` 不用写，`import` 会填；从 draft 来的草稿或 `read` 拿到的书卷里已有的也不用动。
- 每个 `## 标题 {#s1}` 是一节，`{#s1}`、`{#s2}` 依次编号；入藏后不要改，进度和背诵等级按它记录。

## 体裁

- `poem`：诗、词、曲，以及**句式整齐的韵文**：千字文、三字经、弟子规、百家姓、增广贤文、朱子家训等。原文换行会保留，**一联一行**（到「。」或「；」为止，一般 8～16 字），例如：

  ```
  天地玄黄，宇宙洪荒。
  日月盈昃，辰宿列张。
  ```

  不要两联挤一行，也不要整节写成一段：窄侧栏里一行放不下，会折得很乱。
- `prose`：散文、骈文、对韵（如声律启蒙一段里长短句交错），一个自然段一行。
- 拿不准时看节奏：读起来一句一顿、句长整齐的，按 `poem`。

## 分节

- 文章按自然段分节，每节大约 1 分钟读完（100～250 字）。很长的自然段可以在句号处拆成两节，很短的相邻段可以合并。draft 的「第 N 段」只是占位，要改成内容标题，必要时重新拆并（拆并只动空行，不动字）。
- 诗词一首一节；组诗每首一节；长诗按换韵或层次分节（draft 会先按 8 句一节粗分）。
- 韵文每节 6～10 联，按内容层次分，例如千字文「天地四时」「圣王之治」。
- 节标题 2～6 字，概括这一节写什么。诗词以诗题作节标题。
- 每节写一行 `> 脉络：`，20～30 字，说明这一节在全篇里的作用。诗词另有 `> 作者：朝代 · 姓名`（draft 已写好）。

## 注释

- 只注读者可能卡住的地方：生僻字、多音字和古音（写带声调的拼音）、通假字（写作 `通“某”`）、古今异义、词类活用、典故、地名人名。
- 写成 `- 【词】读音：释义`，不需要读音就写 `- 【词】释义`。「词」必须原样出现在本节原文或节标题里，按在原文中出现的顺序排列。
- 释义一般不超过 20 字，典故可以到 40 字。每节 3～12 条为宜。
- 注得密的书卷（如千字文、三字经，每联都有生词），面板默认把注释排在每联下面（「句下」），读音标在字上方；这时释义更要短，**15 字以内**，一条只讲一个意思，不要堆版本异文。
- 读音的音节数和词的字数相同时会标在每个字上方（`【盈昃】yíng zè`）；只给词中一个字注音时（如「巨阙」只注 què），在释义里写明是哪个字：`- 【巨阙】阙读 què：名剑，相传欧冶子所铸`。
- 拿不准的读音或释义宁可不注，或写「一说……」。

## 译文

- 以 `译：` 开头，每节一段，紧跟在注释后面。
- 直译为主，通顺即可，不加评论和发挥。

## 名句

- 用 `==…==` 标出公认名句或最值得背的句子，每节 0～2 处，韵文每节最多 1 处。直接在原文上加标记，不要另抄一遍。
- 标记不能跨行，句末标点放在标记外面，例如 `==欲穷千里目，更上一层楼==。`
- 名句会成为面板「偶遇」里的卡片，宁缺毋滥。

## 配色

- 每卷选一个中国传统色作强调色，写 `color: 色名`。色名必须来自色表（zhongguose.com 526 色），**不要凭印象写**：常见的「苍翠」「朱砂」「天青」都不在表里。
- 用 `action: "colors"` 查，可按 `family`（红、黄、绿、青、蓝、紫、棕、灰…）或 `season`（春夏秋冬）筛选；返回的都是适合作强调色的中等明度色。
- 按篇章意境挑：山水清景取绿、蓝，秋意取棕、灰，边塞取土黄、铁灰，闺怨取紫、粉。拿不准就不写 `color`。
